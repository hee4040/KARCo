# 고정 상대 지식 추정기 검증 결과

이 문서는 수정 전 진단이다. 이후 원래 값 유지와 선택적 보정을 별도 데이터에서 비교한
최신 결과는 SELECTIVE_CALIBRATION.md를 따른다. 미보고 reset에서 악화되는 조건도 함께 보고했다.

검증 실행은 완료했다. 논리 처리는 통과했지만 전체 성능과 보정 지원 범위는 미완료다.
모델을 다시 학습하거나 이번 결과에 맞춰 변경하지 않았다. 현재 D455 기준 이상적 2D 모델의 결과다.

## 고정한 것과 새로 실행한 것

- `data/calibration_repair_v1/selected_model.json`과 같은 폴더의 source 파라미터를 그대로 사용.
- 고정 모델 ID: `7d8d3b39cd3d460095c817d73b5454003961d18b640b96426e62f7fdaaa709a4`.
- 실행 전/후 모델 파일·파라미터 SHA256 일치를 검사. raw 코드 fingerprint와 보정 모델의 일치도 검사.
- 새 offset 0.45/0.95/1.45/1.95m, heading 22/68/158°, 벽 유무, 계획 속도 0.5/1/2m/s.
  offset은 경로 y좌표이며 물체와 경로의 최근접 거리는 별도 열이다. 값은 설계 조건이지 실측치가 아니다.
- 기하 조합 72개에 서로 다른 12개 개입을 적용해 864 에피소드, 4,104 체크포인트를 수집.
- 같은 기하의 통과 결과를 공유하므로 864개의 독립 물리 관측을 했다고 해석하지 않는다.
- 학습 그룹과 episode/session/object_instance/route_group이 겹치면 거절.

메시지 길이는 현재 JSON 직렬화 byte이며 실제 crop/ROS 네트워크 크기 검증은 아니다.

## 논리와 예측 성능을 분리한 결과

시나리오 논리 검사 1,368개는 모두 통과했다. 같은 조건의 반복 검사를 독립 통계 실험으로 세지 않는다.
별도 자동 테스트는 43개 통과했다. 아직 한 번도 처리하지 않은 ACK가 epoch/버전 변경 뒤 늦게
도착하는 경우와 이미 처리한 ACK의 재생을 모두 검사한다.

체크포인트마다 N/C/I로 나눈 총 12,312 항목 중 보정 지원은 9,972개, 미지원은 2,340개다.
N/C/I 모두 보정 가능한 체크포인트는 3,276/4,104개다. 이는 이 개입 구성의 비율이며 실제 운용 지원율이 아니다.
미지원은 오류 0이나 확률 0으로 채우지 않는다. 보정 Brier는 지원된 표본에서만 계산하므로
raw와 cal의 표본이 다르면 그대로 비교하지 않는다. 같은 표본의 paired Brier도 제공한다.

## 추가로 드러난 원인

이전 수정은 pass_by 집단을 다른 집단에서 분리했지만, **같은 ACK 증거 집단 안의 시간 차이**는 분리하지 않았다.
즉, ACK 직후의 올바른 캐시와 오래된 ACK 뒤의 미보고 reset을 같은 보정값으로 취급한다.
선택 모델은 해당 조건에서 raw 1을 N/I 약 0.6667, C 0.75로 낮추기 때문에,
fresh ACK 뒤 정확히 저장된 상태에서도 불필요한 오차를 만든다.
반대로 숨은 reset 뒤에는 그 하향 보정이 평균 오차를 줄인다. 한 평균으로 전체 상황을 판단할 수 없는 이유다.

보정 지원 공백도 남는다. 정상 채널의 전송 대기 시점은 N/C/I 모두 지원하는 경우가 0/72,
통과 없는 전송의 채널 처리 후도 0/72다. 미측정 채널은 채널 처리 후 36/72만 전부 지원한다.
미측정 경로는 통과 직후 N/I를 거절하는 것이 올바른 동작이지만, 현재 모델로 그 경로를 운용할 수 있다는 뜻은 아니다.

## 다음 수정의 경계

현재 모델을 재학습해 이번 평가 결과를 덮지 않았다. 따라서 이번 결과는 미해결 상태의 진단으로 남는다.
후속 후보로 A가 실제 관측하는 증거 경과시간/보고된 epoch·버전 조건을 검토할 수 있다.
보정 표본도 전송 중·통과 없는 전송·부분 ACK·재전송 등 실제 필요한 이력으로 확장해야 한다.
학습에 쓸 데이터와 검증/최종 평가 데이터는 다시 나누고, 지금 본 검증을 미관측 최종 평가로 재사용하지 않는다.
실제 reset·채널 분포의 근거 없이 2D에서 정한 비율을 로봇 확률로 옮기지 않는다.

## 결과 파일과 실행

```powershell
python -m knowledge_estimation.simulation.verify_estimator --output knowledge_estimation/data/estimator_verification_new
python -m unittest discover -s knowledge_estimation/tests -q
```

`data/estimator_verification_v1/`:

- verification_plan.json, frozen_model.json, frozen_parameters.yaml: 실행 전 계획과 고정 모델.
- episodes/: A 관측 입력, 별도 B DB·정답, 기하 trace, source 코드 사본과 checksum.
- predictions.csv: 각 항목 raw/cal/K/R와 미지원 사유.
- metrics_by_case_phase.csv: Brier, 같은 표본의 paired Brier, 표본 수, 평균 점수, 실제 K 비율, 고확신 오류 수.
- coverage_by_case_phase.csv: 상황별 N/C/I 전체 지원 비율.
- reliability_by_case_phase.csv: 사전 고정한 확률 구간별 표본 수·평균 예측·실제 K 비율.
- logic_checks.csv/json, summary.json, RESULTS.md: 논리 검사와 결과 요약.

규칙 기반 선택이나 PPO는 실행하지 않았다. 전체 추정기의 성능·지원 범위는 아직 준비 완료로 판정하지 않는다.
